# 《八戒不会飞》第一版项目文档

《八戒不会飞》是一款面向微信小游戏平台、使用 Cocos Creator 3.x 与 TypeScript 开发的竖屏单手飞行游戏。

玩家连续点击屏幕，让八戒每次扇动大耳朵获得一次向上冲量；停止点击后自由下落，在原创东方天宫世界中穿越由上下障碍物组成的安全通道。

## 当前状态

- 产品阶段：P4「正式素材接入」已完成，下一阶段为 P5「游戏流程」
- 工程标识：`bajie-cannot-fly`
- 引擎版本：Cocos Creator 3.8.8（第一版开发期间锁定）
- 目标平台：微信小游戏
- 屏幕方向：竖屏
- 逻辑分辨率：720 × 1280
- 核心玩法：无尽飞行、穿越障碍、累计分数
- 美术方向：原创东方手绘幻想喜剧风

P4 已将八戒五种姿态、天宫多层背景、六种正式障碍、木牌 UI 和必要特效接入 `core` Asset Bundle；素材异步加载失败时保留可玩的灰盒兜底，视觉节点不改变 P3 的公平性与碰撞判定。

## 工程入口

- Cocos 项目根目录：当前目录。
- 当前启动场景：`assets/scenes/p1_game.scene`（持续演进场景，现已承载 P4 正式素材接入；P5 再统一最终场景命名）。
- Web 调试构建：`build/p1-web`。
- 微信小游戏真机构建与验收：按阶段计划在 P7 执行；P1 以 Creator 场景和 Web 调试构建验收核心玩法。
- 目标操作：每次点击赋予一次向上冲量，连续点击维持飞行，停止点击后自由下落；穿过障碍得分，碰撞后点击重新开始；右上角可暂停。

## 当前已确认的产品决策

- 八戒替代传统飞鸟，耳朵承担翅膀功能。
- 采用 Flappy Bird 式点击飞行：每次有效点击触发一次扑耳并获得固定向上冲量，停止点击后受重力下落。
- 游戏场景为原创天宫与云海。
- 地面障碍物：山峰、石柱、火球。
- 天空障碍物：乌云、雷电、风火轮。
- 上下障碍物形成 3 × 3，共 9 种基础组合。
- 障碍物外观和位置采用受约束随机，不允许生成理论无解局面。
- 静态障碍物：山峰、石柱、乌云。
- 动态障碍物：火球、雷电、风火轮。
- 第一版只实现核心闭环，不加入登录、商业化与联网系统。

## 后续阶段需要锁定

- 目标微信基础库版本与最低机型范围。
- 正式微信小游戏 AppID；当前调试构建使用 Creator 生成的测试配置。
- 最终美术资源尺寸和音频编码，以真机内存测试结果为准。
- 是否在第一版加入分享按钮；默认不加入，不影响核心闭环。
