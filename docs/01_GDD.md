# 《八戒不会飞》游戏设计文档（GDD）

文档版本：V1.1 点击操作需求基线  
适用版本：第一版  
目标平台：微信小游戏

## 1. 产品概述

《八戒不会飞》是一款竖屏、单手操作的无尽飞行小游戏。玩家控制一个圆滚滚的原创八戒形象，通过连续点击让两只大耳朵一次次扑动，在云海天宫中穿过上下成对出现的障碍物。

游戏强调三种体验：

- 一秒能懂的点击扑动操作。
- “胖八戒努力飞行”的反差喜剧。
- 看似轻松、实际需要节奏控制的挑战。

## 2. 核心体验支柱

### 2.1 操作简单，手感可控

玩家只需要有节奏地点击屏幕。每次点击的飞行响应必须一致、即时、可预判，不能因为触摸采样、帧率变化或物理抖动产生不可控结果。

### 2.2 死亡有因，随机公平

障碍物可以随机，但安全空间必须由规则保证。动态障碍必须提供预警，碰撞区应比视觉危险范围略宽松。

### 2.3 角色比系统更有记忆点

八戒的耳朵、表情、喘气、冒汗和撞击反应是产品识别核心。即使关闭声音，也应该能从动作中理解角色状态。

### 2.4 天宫是冒险空间，不是静态壁纸

远处仙山、瀑布、云层、树叶和风铃通过不同速度移动，持续建立高空飞行感，但不能干扰障碍识别。

## 3. 目标用户与单局时长

- 目标用户：喜欢轻量休闲、反应挑战与可爱角色的微信用户。
- 学习成本：首次进入 10 秒内掌握。
- 预期新手单局：15～45 秒。
- 熟练玩家单局：1～5 分钟或更长。
- 使用场景：碎片时间、单手操作、可快速重开。

## 4. 游戏循环

主循环如下：

标题界面 → 点击开始 → 短暂准备 → 控制飞行 → 穿越障碍得分 → 难度提高 → 撞击失败 → 查看得分 → 重新开始

### 4.1 开始

- 点击“开始游戏”进入游戏场景。
- 八戒出现在屏幕左侧约 28% 的水平位置、垂直中央略上。
- 出现“点击起飞，连续点击保持高度”的首次引导。
- 首次有效点击后，八戒获得一次向上冲量，障碍物开始移动并正式计时。

### 4.2 游戏进行

- 八戒只进行垂直运动和小角度旋转。
- 场景和障碍物持续向左移动，制造向前飞行的视觉效果。
- 每穿过一整组障碍物，增加 1 分。
- 分数提高后逐步增加世界速度、动态障碍概率，并略微缩小安全通道。

### 4.3 失败

满足任一条件即失败：

- 八戒有效碰撞体与任意障碍碰撞。
- 八戒触碰游戏区顶部危险边界。
- 八戒完全跌出游戏区底部。

失败后：

1. 立即停止得分和生成。
2. 世界进入短暂慢动作或停顿，突出撞击反馈。
3. 八戒播放受伤并坠落动画。
4. 显示本局分数、最高分和重新开始按钮。

## 5. 操作设计

### 5.1 输入规则

- `Touch Start`：在非 UI 区域触发一次飞行点击，立即向 FlightMotor 提交一次向上冲量。
- `Touch End`：不改变飞行状态，不额外施力。
- `Touch Cancel`：不产生补偿冲量，也不影响后续点击。
- 第一版只响应第一个有效触点，忽略额外触点。
- UI 按钮触摸不得透传给飞行控制。
- 一次物理触摸最多产生一次冲量；禁止同时监听触摸与鼠标事件造成双触发。

### 5.2 飞行规则

- 每次有效点击把垂直速度设置为或修正到配置的向上扑动速度；采用哪种冲量合成方式以 P6 手感测试结果为准，首轮使用“重置为固定向上速度”。
- 点击之间始终施加重力，因此停止点击后会自然下落。
- 上升和下降均设最大速度。
- 角色角度根据当前垂直速度平滑变化。
- 暂停、结算和后台状态忽略飞行点击；恢复游戏时不得补发点击。

### 5.3 操作反馈

- 每次有效点击触发一轮短促扑耳动画、轻微气流线和扑动音效。
- 连续快速点击时动画可以重启或衔接，但音效必须限制并发，避免叠加爆音。
- 停止点击后耳朵逐渐上翻，八戒随下落速度逐渐头朝下。
- 接近障碍物但未碰撞时可以播放一次短促紧张表情，不改变判定。

## 6. 障碍物系统

### 6.1 障碍组合

每个障碍组由一个天空障碍和一个地面障碍组成。

| 天空障碍 | 地面障碍 | 组合类型 |
|---|---|---|
| 乌云 | 山峰 | 双静态 |
| 乌云 | 石柱 | 双静态 |
| 乌云 | 火球 | 单动态 |
| 雷电 | 山峰 | 单动态 |
| 雷电 | 石柱 | 单动态 |
| 雷电 | 火球 | 双动态 |
| 风火轮 | 山峰 | 单动态 |
| 风火轮 | 石柱 | 单动态 |
| 风火轮 | 火球 | 双动态 |

### 6.2 山峰

- 类型：地面静态。
- 行为：随世界向左移动，无自身运动。
- 视觉：尖锐岩峰、苔藓和少量贴地云雾。
- 判定：碰撞体贴合主体岩石，忽略细小草叶和薄雾。

### 6.3 石柱

- 类型：地面静态。
- 行为：随世界向左移动，无自身运动。
- 视觉：天宫遗迹石柱，带裂纹、祥云或莲纹浮雕。
- 变体：可有不同破损外形，但首版碰撞尺寸由配置控制。

### 6.4 火球

- 类型：地面动态。
- 行为：沿垂直方向小幅正弦浮动，同时持续旋转。
- 视觉：黄色核心、橙红火焰和少量火星拖尾。
- 判定：只覆盖火球核心及主要外焰，不包含稀疏拖尾粒子。

### 6.5 乌云

- 类型：天空静态。
- 行为：位置固定，内部纹理可以缓慢翻滚。
- 视觉：蓝灰或紫灰色，与背景暖白云明显区分。
- 判定：覆盖浓密云体，不包含半透明边缘。

### 6.6 雷电

- 类型：天空动态、周期危险。
- 状态：休眠 → 预警 → 激活 → 冷却。
- 预警：乌云内部闪烁，攻击区域出现低透明度电光。
- 激活：雷电实体出现并进入可碰撞状态。
- 原则：玩家首次遇到时也必须来得及理解和反应。

### 6.7 风火轮

- 类型：天空动态。
- 行为：持续旋转，沿垂直方向小幅往复运动。
- 视觉：金铜色轮体、红橙火焰与短拖尾。
- 判定：以轮体为主，火焰尖端给予容错。

## 7. 障碍生成原则

- 先确定安全通道，再放置上下障碍物，禁止两个障碍独立盲目随机。
- 通道中心点变化受到最大步长约束。
- 通道高度始终大于配置中的最低安全值。
- 动态障碍按其完整运动范围计算最坏情况下的安全空间。
- 双动态组合不能在新手阶段出现。
- 连续动态组合数量受限，避免连续高压局面。
- 生成结果通过公平性验证后才进入场景；不合格结果重新采样。

详细规则见《数值与生成规则》。

## 8. 得分与难度

### 8.1 得分

- 八戒的水平位置越过障碍组计分线时获得 1 分。
- 每组障碍只能得分一次。
- 失败状态、暂停状态不计分。
- 当前分数在游戏上方中央显示。

### 8.2 最高分

- 历史最高分保存在本地。
- 仅在本局分数高于历史记录时更新。
- 结算时以印章或光效突出“新纪录”。

### 8.3 难度来源

难度只能从以下维度平滑提升：

- 世界横向移动速度。
- 安全通道高度。
- 动态障碍出现权重。
- 动态障碍运动速度。
- 相邻安全通道中心点变化范围。

禁止通过突然改变重力、隐藏预警或改变碰撞规则制造难度。

## 9. 游戏状态

| 状态 | 说明 | 接受飞行输入 |
|---|---|---|
| Loading | 加载必要资源 | 否 |
| Menu | 标题界面与待机动画 | 否 |
| Ready | 等待首次按下 | 是 |
| Playing | 正常游戏 | 是 |
| Paused | 主动暂停或切到后台 | 否 |
| Hit | 撞击反馈阶段 | 否 |
| Result | 结算界面 | 否 |

所有状态切换由统一状态机管理，不允许多个脚本各自判断是否已经失败。

## 10. 界面流程

### 10.1 标题界面

- 顶部木牌：游戏标题。
- 中部：八戒悬浮待机。
- 底部主要按钮：开始游戏。
- 次要按钮：声音设置。
- 第一版不放置无功能入口。

### 10.2 游戏界面

- 顶部中央：当前分数。
- 右上角：暂停。
- 首局中央偏下：操作引导，首次有效点击后淡出。
- 刘海屏和圆角区域使用安全区适配。

### 10.3 暂停界面

- 继续游戏。
- 重新开始。
- 返回标题。
- 音乐和音效开关可合并为一个声音开关。

### 10.4 结算界面

- 本局分数。
- 历史最高分。
- 新纪录标识。
- 重新开始。
- 返回标题。

## 11. 视听方向

- 风格名称：原创东方手绘幻想喜剧风。
- 背景：明亮云海、漂浮仙山、亭台与瀑布。
- 主色：天空蓝、暖白、苔藓绿和木质棕。
- 危险色：火焰橙红、电光蓝紫。
- 音乐：轻快东方幻想，避免过度宏大。
- 耳朵扑动、风声、火焰和雷击必须有明显但不刺耳的声音反馈。

完整规范见《美术与视听规范》。

## 12. 新手体验

- 首次进入时，只显示一句操作说明：“点击起飞，连续点击保持高度”。
- 用手指图标配合连续点按和八戒逐次上升的动画演示。
- 引导期间第一组障碍只能为双静态组合。
- 前 3 分不出现双动态组合。
- 玩家第一次失败后直接突出“再来一次”，不弹出额外教学窗口。

## 13. 暂停与生命周期

- 玩家点击暂停按钮后，角色、世界、动态障碍、动画计时和音效全部暂停。
- 微信小游戏进入后台时自动暂停。
- 回到前台后保持暂停界面，由玩家主动继续。
- 进入后台后清空未处理的输入事件；恢复时必须由玩家再次点击才会获得冲量。

## 14. 第一版不做的设计

- 不设置复活。
- 不设置道具和技能。
- 不设置关卡终点。
- 不设置随机奖励或货币。
- 不把装饰物作为无提示的碰撞障碍。
- 不使用广告打断首版玩法验证。
