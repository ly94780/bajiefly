# 《八戒不会飞》美术与视听规范

## 1. 风格定义

项目使用“原创东方手绘幻想喜剧风”。目标是营造温暖、通透、自然、有生活气息的云上世界。

可使用的描述词：

- 东方神话幻想。
- 手绘动画质感。
- 水彩与绘本纹理。
- 柔和自然光。
- 圆润、憨态、轻喜剧。
- 云海、漂浮仙山和木质手作感。

生产素材和生成式工具提示词中，不直接要求复制在世艺术家或具体动画工作室的独特风格。不得照搬现有影视作品中的猪八戒服装、脸型、兵器、配色或镜头。

项目风格参考图：`../Codex 图像 2026年9月18日 11_49_00.png`。该图片只用于拆解氛围、构图、色彩和材质，不作为可以直接切图使用的游戏资源。

## 2. 视觉原则

### 2.1 轮廓优先

移动端实际显示较小。角色和障碍物缩小后，必须仅凭轮廓仍能识别。

### 2.2 前景清晰，背景克制

- 背景使用较低对比度、较低饱和度和空气透视。
- 玩家和障碍物拥有更明确的明暗边界。
- 危险物体可使用局部辉光，但不使用粗重黑描边。

### 2.3 质感统一

- 岩石、木头、布料、云雾均带柔和手绘纹理。
- 不混用照片写实贴图、像素风和纯扁平矢量图标。
- 所有资源的主光方向统一为左上或右上，项目启动时选定后全局保持一致。

### 2.4 装饰不能误导

- 可碰撞物体具有清晰主体边缘。
- 不可碰撞装饰降低对比度，不采用尖锐、高亮危险造型。
- 背景白云不得与作为障碍物的乌云混淆。

## 3. 色彩基线

以下为首轮建议色，不要求逐像素一致：

| 用途 | 建议色 | 说明 |
|---|---|---|
| 天空顶部 | `#3E9CEB` | 明亮但不过度荧光 |
| 天空底部 | `#BFEAFF` | 接近云海的浅青蓝 |
| 暖白云 | `#FFF3D6` | 避免纯白刺眼 |
| 八戒皮肤 | `#F29B86` | 桃粉暖色 |
| 八戒高光 | `#FFD0B6` | 面部和耳朵透光 |
| 八戒服装 | `#34465B` | 深蓝灰，衬托皮肤 |
| 围巾 | `#A84F36` | 暖红棕 |
| 木质 UI | `#795139` | 中等暖棕 |
| 苔藓 | `#718A47` | 偏灰自然绿 |
| 岩石 | `#77766D` | 中性灰褐 |
| 乌云 | `#59637C` | 蓝紫灰 |
| 火焰核心 | `#FFD35A` | 高明度黄色 |
| 火焰外层 | `#EE6337` | 危险橙红 |
| 雷电 | `#C9E9FF` | 蓝白高亮 |
| 雷电暗部 | `#7669C5` | 蓝紫边缘 |

确保八戒与相邻背景的亮度差足够明显。不得只用颜色区分危险，还应同时使用形状、动画和音效。

## 4. 角色规范

### 4.1 八戒剪影

- 身体近圆形，肚子突出。
- 耳朵宽大，左右张开后成为主要横向轮廓。
- 手脚短小，不承担主要识别功能。
- 面部位于身体上半部，眼睛和嘴巴可夸张变形。
- 服装简化为深色短褂、围巾和小包袱，避免细节过多。

### 4.2 表情语言

- 待机：自信中带一点心虚。
- 上升：咬牙、鼓劲、轻微冒汗。
- 快速下落：眼睛向下看、嘴巴张开。
- 擦身而过：闭眼缩肚。
- 撞击：脸部挤压、短暂星星眼。
- 结算：耳朵垂下，但保持喜剧感，不表现真实伤害。

### 4.3 动画清单

| 动画 | 建议方式 | 最低要求 |
|---|---|---|
| MenuIdle | 逐帧或分层 | 浮动、眨眼、缓慢扇耳 |
| ReadyIdle | 逐帧或程序混合 | 小幅悬停 |
| FlyUp | 逐帧 | 耳朵快速上下扑动 |
| Fall | 逐帧或姿态混合 | 耳朵上翻、表情慌张 |
| NearMiss | 叠加表情 | 缩肚或冒汗 |
| Hit | 逐帧 + 程序旋转 | 挤压、星星粒子 |
| Result | 逐帧 | 喘气、耳朵垂下 |

首版优先使用 SpriteFrame 逐帧动画或少量节点分层动画，不引入复杂换装骨骼系统。

### 4.4 游戏尺寸

- 视觉宽度建议约为屏幕宽度的 14%～17%。
- 角色碰撞体只覆盖身体主体，耳朵尖端给予宽容。
- 菜单中的八戒可以放大，但游戏内尺寸必须固定并经过通道验证。

## 5. 背景规范

### 5.1 层级

至少拆分为：

1. 天空渐变。
2. 远云与薄雾。
3. 远景漂浮仙山和天宫。
4. 中景仙山、瀑布或云桥。
5. 可选前景树叶、绳索或云雾。

### 5.2 视差

- 天空不动或极慢。
- 远云最慢。
- 远景仙山较慢。
- 中景接近但低于游戏世界速度。
- 前景略快于世界速度，出现频率低。

背景必须支持无明显接缝的循环。前景元素不能长时间遮挡八戒或安全通道。

### 5.3 天宫元素

允许使用：

- 原创飞檐亭台。
- 悬浮岩岛和瀑布。
- 祥云纹、木桥、绳索、纸灯笼和风铃。
- 小型远景飞鸟。

避免在单屏堆放过多建筑，防止视觉噪音。

## 6. 障碍物规范

### 6.1 山峰

- 三角形或不规则尖峰剪影。
- 灰褐岩石配少量苔藓。
- 顶部不得使用过细的尖刺作为实际判定区。

### 6.2 石柱

- 竖向轮廓清晰，顶部可以破损。
- 浮雕图案控制在大块面，不绘制游戏尺寸下不可见的小纹样。
- 与山峰通过人工建筑形态明显区分。

### 6.3 火球

- 明亮核心确保在任何背景上可见。
- 火星和拖尾是表现层，不进入碰撞体。
- 旋转方向和浮动节奏应清晰但不眩晕。

### 6.4 乌云

- 形状厚重，下缘略尖或卷曲。
- 使用蓝紫灰，与普通白云区分。
- 可以有微弱内部闪光，但不能让玩家误以为一定会落雷。

### 6.5 雷电

- 预警电光低透明、节奏稳定。
- 激活电光高亮，边缘带蓝紫色。
- 闪屏强度受限，避免大面积纯白频闪。

### 6.6 风火轮

- 金铜轮体形成明确圆形判定认知。
- 外圈火焰短而粗，不制作过长拖尾。
- 旋转动画需要在低帧率下仍可辨认。

## 7. UI 规范

- 标题使用悬挂木牌与手写笔触。
- 主要按钮使用木牌、纸签或印章造型。
- 分数使用高可读圆体或授权字体，不强行使用复杂毛笔字。
- 标题和短文案可用毛笔风字体，但必须确认商用授权。
- 按钮至少具备正常、按下和禁用状态。
- 所有重要内容避开设备安全区。
- 不使用参考图中文字直接作为界面文案。

### 7.1 菜单构图

- 上方：标题木牌。
- 中部：八戒待机动画。
- 后方：云海、漂浮仙山与天宫。
- 下方：开始游戏主按钮。
- 边缘：少量灯笼、风铃或纸签，不能抢夺主按钮注意力。

### 7.2 游戏构图

- 八戒位于屏幕左侧约 28%。
- 安全通道主要出现在屏幕中部。
- 当前分数位于顶部安全区下方。
- 暂停按钮放置于右上安全区内。

## 8. 特效规范

- 扇耳气流：短、柔和、半透明白色曲线。
- 火星：数量少，橙黄色，生命周期短。
- 雷电：先预警、后激活，禁止无提示突然满屏闪白。
- 撞击：小型星星、云团和轻微屏幕震动。
- 新纪录：红色印章、少量金色粒子。
- 树叶：作为前景气氛，单次最多少量经过。

特效不得扩大实际碰撞判定，也不得遮挡安全通道。

## 9. 音乐与音效

### 9.1 音乐

- 轻快、清新、略带笨拙喜剧感。
- 可使用竹笛、拨弦、木质打击和轻柔风铃音色。
- 游戏音乐应支持自然循环。
- 不使用现有影视动画旋律或相似度过高的主题动机。

### 9.2 必需音效

- UI 点击。
- 游戏开始。
- 耳朵扑动。
- 上升气流。
- 穿越得分。
- 火球燃烧。
- 雷电预警与雷击。
- 风火轮旋转。
- 撞击。
- 新纪录。

高频音效必须设置播放间隔，防止叠加爆音。

## 10. 资源交付规则

- 原始美术文件与导出文件分开管理。
- 文件名只使用英文小写、数字和下划线。
- 资源命名示例：`player_fly_up_01.png`、`obstacle_fireball.png`。
- 导出前裁切多余透明区域，并记录 Pivot。
- 同一动画帧尺寸、中心点和像素密度保持一致。
- 所有碰撞体由程序侧单独配置，不根据 Alpha 自动生成复杂轮廓。
- 每批资源必须在 720 × 1280 真机画面比例下检查，而不是只看原始大图。
