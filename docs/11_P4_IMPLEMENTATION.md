# 《八戒不会飞》P4 正式素材接入与验收记录

## 1. 阶段结论

P4 已将现有原创东方手绘幻想素材接入持续演进场景 `assets/scenes/p1_game.scene`。P1～P3 的飞行、计分、对象池、随机组合、动态障碍和碰撞数值保持不变。

运行时先创建可交互灰盒，再异步加载 `core` Asset Bundle；素材加载成功后原位替换，加载失败时保留灰盒并输出明确错误，不会出现空白游戏。

## 2. 本阶段产出

### 2.1 资源加载

- `assets/bundles/core.meta`：将现有正式素材目录配置为 `core` Asset Bundle。
- `assets/scripts/art/P4ArtAssets.ts`：集中管理 角色、背景、障碍、UI 与 VFX 的资源路径和异步加载。
- 素材文件名、目录和代码路径统一使用小写英文与下划线，不使用中文运行时路径。

### 2.2 八戒表现

- Ready：`player_bajie_idle`。
- 点击扑耳与上升：`player_bajie_fly_up`，附带短促气流。
- 下落：`player_bajie_fall`。
- 碰撞：`player_bajie_hit`，叠加碰撞云。
- 结算：`player_bajie_result`。

角色图片仅负责视觉表现，圆形碰撞半径仍由 `FlightConfig` 控制，耳朵尖端不进入碰撞范围。

### 2.3 天宫背景

- 天空底图覆盖 720 × 1280 设计画布。
- 远云、远景仙山和中景仙山分层显示，并继续复用已有视差移动逻辑。
- 背景层低于角色、障碍、HUD，不改变可玩空间和碰撞。

### 2.4 障碍表现

- 地面：山峰、石柱、火球全部替换为正式 Sprite。
- 天空：乌云、雷电、风火轮全部替换为正式 Sprite。
- 火球继续上下浮动，风火轮继续浮动并旋转。
- 雷电继续采用休眠、预警、激活、冷却四阶段；预警态降低透明度，激活态全亮。
- 视觉节点与碰撞计算分离，透明拖尾、辉光和装饰不会扩大判定。

### 2.5 UI 与特效

- 顶部标题接入木牌素材。
- 暂停区域接入正式图标。
- 结算面板接入正式面板素材。
- 扑耳气流和碰撞云已接入；得分闪光资源已纳入预载表，留给 P5 流程表现使用。
- 旧的 `ui_gesture_hold.png` 未接入，因为操作已改为连续点击；避免向玩家传达错误操作。

## 3. 运行验证

在 Cocos Creator 3.8.8 中：

1. 打开项目根目录。
2. 打开 `assets/scenes/p1_game.scene`。
3. 停止旧预览并重新点击运行，确保 Creator 重新导入 Bundle 和脚本。
4. Ready 标题应显示“八戒不会飞 · P4 正式素材版”。
5. 检查八戒五种姿态、三层视差、六种障碍、雷电预警、暂停冻结、碰撞与重开。

若画面仍显示 P3 标题，说明旧预览未重编译，应停止预览后重新运行，而不是只刷新浏览器页面。

## 4. 验收结果

- Cocos Creator 3.8.8 TypeScript 严格检查：通过。
- P2 公平性回归：沿用相同生成器边界，无规则修改。
- P3 动态障碍回归：运动和碰撞方法未改，正式图片仅作为表现层。
- 资源加载失败兜底：已实现。
- 正式素材路径集中管理：已实现。

仍需在 P7 对微信真机进行纹理内存、压缩格式、小屏识别度和低端机帧率验收；这些不属于桌面 P4 的可替代项。
