# 《八戒不会飞》点击操作变更说明

状态：已确认并完成代码改造  
记录日期：2026-09-19

## 1. 变更结论

第一版不再采用“长按持续上升、松开自由下落”。目标操作改为接近 Flappy Bird 的点击节奏：

- 每次有效点击屏幕，八戒扇动一次耳朵并立即获得一次向上冲量。
- 玩家连续多次点击，可以持续修正高度并维持飞行。
- 两次点击之间始终受重力影响；停止点击后自然下落。
- 一次触摸只能产生一次冲量，按住不持续施力。

## 2. 采用原因

- 点击节奏比持续按压更明确，单次输入反馈更直接。
- 玩家可以用点击频率控制高度，形成容易理解但有熟练空间的操作循环。
- 与无尽穿越障碍的短节奏判断更匹配，也更符合用户对 Flappy Bird 类玩法的预期。

## 3. 已完成的代码工作

产品负责人确认后，已完成以下代码改造：

1. 输入从持续 `holding` 状态改为单次 `flap` 事件。
2. FlightMotor 从持续推力改为点击时设置固定向上速度。
3. 删除依赖 `Touch End` 的飞行状态切换；保留输入生命周期和多指去重。
4. 修改 HUD、首次教学和调试字段。
5. 耳朵灰盒动画改为每次点击触发一轮短促扑动。
6. 增加冲量、重力、重复点击、停止下落和速度防叠加自动测试。

## 4. 首轮实现基线

- 输入触发：非 UI 区域的 `Touch Start`。
- 冲量策略：`velocityY = flapVelocity`，不累加无限冲量。
- 初始 `flapVelocity`：430 逻辑像素/秒。
- 重力初始值：-1450 逻辑像素/秒²。
- 上升速度上限：430 逻辑像素/秒。
- 下落速度上限：-650 逻辑像素/秒。

这些数值只用于第一轮可玩版本，P6 根据真机点击节奏继续调整。

## 5. 确认实施后的验收标准

- 单击一次只产生一次明显上升响应。
- 按住屏幕不持续上升。
- 连续点击能够稳定控制高度。
- 停止点击后八戒立即进入仅受重力影响的运动。
- 快速点击不漏触发，也不发生一次点击触发两次的情况。
- 点击暂停等 UI 按钮不会让八戒扑动。
- 多指输入不会叠加异常冲量。
- 暂停、切后台、结算和重新开始之间没有残留输入。
- 原有障碍、碰撞、计分、对象池、最高分和状态流程继续正常。

## 6. 美术与提示文案影响

- 操作提示改为：“点击起飞，连续点击保持高度”。
- 原素材 `ui_gesture_hold.png` 不再符合目标含义，P4 前替换为连续点击引导素材，建议命名 `ui_gesture_tap.png`。
- `player_bajie_fly_up.png` 继续复用，但语义变为点击扑耳后的上升姿态。
- 每次有效点击触发扑耳动画、气流和音效；高频点击时需要限制音效并发。

## 7. 历史实现说明

P0 和 P1 的实施记录描述的是已经完成的旧版长按实现，因此保留原始验收事实，并在文档顶部标注其已被新需求取代。这样既避免把历史记录改成未实际发生的结果，也能明确当前代码和目标需求之间的差异。
